StarBridge SMS Consent Policy

This page describes how StarBridge OS uses SMS messaging and how consent (opt-in) is collected.

Message Purpose (Use Case)

  • System alerts and notifications
  • Command confirmations and status responses
  • Account / device operational messages

No marketing or promotional messaging is sent.

Opt-In / Consent Collection

SMS messages are only sent to phone numbers that have explicitly opted in to receive StarBridge system notifications. Consent may be collected in one or more of the following ways:

  • Manual onboarding where the user provides their phone number and requests SMS notifications
  • Direct written consent (email, form, or message) requesting SMS notifications
  • In-product setting that enables SMS notifications (when available)

Users can withdraw consent at any time using the opt-out instructions below.

Opt-Out and Help

  • Reply STOP to opt out at any time.
  • Reply HELP for assistance.

Support: support@starbridgeos.com

Message Frequency

Message frequency varies based on system events and user-initiated commands.

Fees

Message and data rates may apply depending on your mobile carrier plan.

Privacy

StarBridge uses phone numbers solely for system notification and messaging purposes described above.
